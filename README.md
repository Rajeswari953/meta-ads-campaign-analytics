# Meta Ads Campaign Performance Analytics

Interactive portfolio dashboard for analysing Facebook and Instagram advertising campaign performance.

## What it does
- Calculates Spend, Impressions, Reach, Clicks, CTR, CPC, CPM, Conversions, Conversion Rate and Cost per Conversion
- Compares campaign and platform performance
- Provides date, campaign and platform filters
- Shows performance trends and a campaign KPI table
- Generates simple data-driven observations

## Tech Stack
Python | Pandas | NumPy | Plotly | Streamlit

## Data
`data/meta_ads_sample.csv` is synthetic data created for this portfolio project. It does not contain Zippy Digital Solutions' confidential campaign data.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Internship connection
This project is a portfolio implementation based on the type of Meta Ads performance analysis learned during a Meta Ads Analyst internship. It is not an official Zippy Digital Solutions project and does not reproduce company data.
